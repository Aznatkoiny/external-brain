# Relationship vocabulary

Use these terms in prose when they clarify why pages are connected:

| Relationship | Use when |
| --- | --- |
| `supports` | Evidence increases support for a claim without proving it universally |
| `challenges` | Evidence weakens or narrows a claim |
| `extends` | A work adds capability, scope, data, or theory to earlier work |
| `replicates` | A work intentionally tests a prior result with a comparable design |
| `fails-to-replicate` | A comparable test does not reproduce a prior result |
| `applies` | A method or idea is used in a new setting |
| `defines` | A source gives an operative definition of a concept |
| `depends-on` | A claim or method requires another assumption or component |
| `operationalizes` | A study turns an abstract construct into a measurable procedure |
| `distinguishes` | A note explains a consequential difference between related concepts |
| `potential-conflict` | Two grounded statements may be incompatible but require human judgment |

Relationships are claims, not decorative edges. State the basis and cite it. Agents may write established source-described relationships directly; inferred relationships use `status: agent-proposed`. Only a human promotes `potential-conflict` to a confirmed contradiction.
